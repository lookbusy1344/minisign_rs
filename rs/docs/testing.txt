WEAK KEYS
=========

Generate a weak key intentionally:
cargo run -- -G -s weak_private.key -p weak_public.pub --force-weak-kdf

Signing with weak key:
minisign_rs --sign -m SSMS20.exe --secretkey-path ./weak_private.key -t 'This is a trusted comment from RS version with WEAK KEY'
minisign -Sm SSMS20B.exe -s ./weak_private.key -t 'This is a trusted comment from classic C version with weak key. No warnings'

Cross verify:
minisign -Vm SSMS20.exe -p ./weak_public.pub
minisign_rs -Vm SSMS20.exe -p ./weak_public.pub

minisign_rs -Vm SSMS20B.exe -p ./weak_public.pub
minisign -Vm SSMS20B.exe -p ./weak_public.pub

Inspect:
minisign_rs -Ip weak_public.pub
minisign_rs -Is weak_private.key

Remove those signatures:
rm SSMS20.exe.minisig
rm SSMS20B.exe.minisig


Strong keys
===========

Generate:
minisign_rs -G -s strong_private_r.key -p strong_public_r.pub
minisign -G -s strong_private_c.key -p strong_public_c.pub

Inspect:
minisign_rs -Is strong_private_c.key --no-decrypt
minisign_rs -Is strong_private_c.key
minisign_rs -Is strong_private_r.key

minisign_rs -Ip strong_public_c.pub
cat strong_public_c.pub
minisign_rs -Ip strong_public_r.pub
cat strong_public_r.pub

Cross signing:
minisign_rs --sign -m SSMS20.exe --secretkey-path ./strong_private_c.key -t 'This is a trusted comment from RS version with strong C key'
minisign -Sm SSMS20B.exe -s ./strong_private_r.key -t 'This is a trusted comment from classic C version with strong Rust key'
